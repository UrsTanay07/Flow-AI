# Security policy

## Supported version

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting flow for this repository and include reproduction
steps, affected routes, and likely impact. Avoid including credentials or
personal traffic data in the report.

## Operational boundary

FlowAI runs in planning mode unless an authorized controller integration is
implemented and independently reviewed. Demo accounts and demonstration data
must not be used as production identity or telemetry sources.
