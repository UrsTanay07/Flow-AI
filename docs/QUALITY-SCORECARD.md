# Seventeen-area quality scorecard

1. **Visual design:** editorial FlowAI palette, typography, hierarchy, and surfaces.
2. **Design system:** shared tokens and reusable card/button/page primitives.
3. **Usability:** clear primary actions, status labels, recovery, and empty states.
4. **Accessibility:** semantic landmarks, labels, focus visibility, reduced motion.
5. **Responsive design:** adaptive navigation, headers, grids, tables, and map controls.
6. **Information architecture:** six task-focused views with stable deep links.
7. **Frontend architecture:** strict TypeScript, lazy routes, error boundary, shared API.
8. **Backend architecture:** separated API app, atomic persistence, bounded audit history.
9. **Real-time data:** authenticated server-sent events with polling fallback.
10. **Data integrity:** provider validation, provenance labels, timestamps, safe fallback.
11. **Authentication:** server-owned sessions, secure cookies, throttled login.
12. **Authorization:** observer, engineer, and administrator role boundaries.
13. **Application security:** CSRF, payload limits, security headers, request IDs.
14. **Performance:** route splitting, cached provider reads, static production assets.
15. **Testing:** authentication, authorization, operations, predictions, readiness, SSE.
16. **Operations and observability:** health/readiness, structured logs, Docker healthcheck.
17. **CI/CD and maintenance:** reproducible installs, quality gate, container build,
    dependency updates, architecture, security policy, and runbook.
